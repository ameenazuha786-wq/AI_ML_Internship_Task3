# AI/ML Internship Task 3 – Exploratory Data Analysis

## Objective
The objective of this task is to perform Exploratory Data Analysis (EDA) on a Housing dataset using Python.

## Dataset
The dataset contains housing information such as:
- Price
- Area
- Bedrooms
- Bathrooms
- Stories
- Main road
- Guest room
- Basement
- Hot water heating
- Air conditioning
- Parking
- Preferred area
- Furnishing status

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- VS Code

## EDA Performed
The following analysis was performed:
1. Displayed the first five rows of the dataset.
2. Checked the dataset information and shape.
3. Checked for missing values.
4. Checked for duplicate rows.
5. Analyzed the distribution of house prices.
6. Analyzed the distribution of house area.
7. Studied the relationship between house area and price.
8. Analyzed the distribution of bedrooms.
9. Compared average house prices based on furnishing status.

## Output Graphs
The repository contains the graphs generated during the analysis, including:
- Distribution of House Prices
- Distribution of House Area
- House Price vs Area
- Distribution of Bedrooms
- Average House Price by Furnishing Status

## Conclusion
The exploratory data analysis provides useful insights into the Housing dataset. The analysis shows the distribution of important housing features and the relationship between house area, price, bedrooms, and furnishing status.
